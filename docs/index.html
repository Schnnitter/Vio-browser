About

About

Vio is a modern desktop web browser written with Electron. It uses the Chromium engine to render the web and Node.js to talk to your operating system, and it wraps both in a small, clean interface that stays out of your way.

The goal is simple: a browser that opens fast, looks calm and does not bury the page you are reading under toolbars and clutter.

Fast and light

A minimal interface built for smooth, responsive browsing.

Full navigation control

Tabs, back and forward history, and a proper address bar.

Windows

Built for Windows through Electron.

Minimalist design

No clutter, so your attention stays on the content.

Open source

MIT licensed. Read it, fork it, change it.

Localization-ready

The repository includes translation audit files for interface strings.

Get Vio

Until then you can run Vio from source in a couple of minutes. You only need two free tools:

ToolWhat it is forDownload
Node.js (LTS)Runs and installs the appnodejs.org/en/download
GitDownloads the source codegit-scm.com/downloads

Run Vio from source

git clone https://github.com/Schnnitter/Vio-browser.git
cd Vio-browser
npm install
npm start

That is all. The first npm install downloads Electron, so it can take a little while.

You can also skip Git and download the code as a ZIP: Download ZIP. Unpack it, open a terminal in the folder and run the last two commands.

Supported system

Vio runs on Windows. The exact list of supported versions is maintained by the Electron team, see Electron platform support.

Troubleshooting

npm install fails while building a native module. Vio uses better-sqlite3, which is a native module. If no prebuilt binary matches your system, npm compiles it locally and needs a C++ toolchain.

SystemWhat to install
WindowsVisual Studio Build Tools with the C++ workload, and Python

The window does not open. Run npm start from a terminal and read the output. Error messages there are the fastest way to find the cause, and they are exactly what we need in a bug report.

Found a bug or have an idea? Open an issue and describe what happened, what you expected and your operating system.

How it fits together

Like every Electron app, Vio is split into processes that talk to each other through well-defined channels.

main.js
Main process · Node.js ↔ IPC preload.js
Preload bridge ↔ contextBridge index.html + styles.css
Interface · Chromium
main.js → writes SQLite
local data · interface → renders Web pages
Chromium engine

If you are new to the model, the official guides explain it well: Process Model, Context Isolation and Inter-Process Communication.

Building installers

Packaging is not configured in the repository yet. When you are ready to ship installers, the two common options are:

ToolBest forLink
electron-builderQuick setup, installers and auto-updateelectron.build
Electron ForgeOfficial all-in-one toolchain from the Electron teamelectronforge.io

Remember that native modules such as better-sqlite3 must be built against Electron's own Node.js version, not the one installed on your machine. Both tools above can handle this step for you.

Contributing

Contributions of every size are welcome, from a typo in the interface to a new feature.

1
Fork the repository.
2

3
Make your change and run npm run check.
4
Commit with a clear message and push the branch.
5
